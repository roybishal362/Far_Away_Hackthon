# docs/ — images for the README (optional)

The README already looks complete on its own (the architecture diagrams render automatically and the
proof chart is committed). These images are **optional polish** — add any of them to make it pop.

Each one is referenced as a **commented-out line** in the main [README](../README.md). After you add a
file here, open the README and **uncomment** the matching line.

| File to add here | Where it shows up | How to get it |
|---|---|---|
| `hero.jpg` | Top banner of the README | Your cherry-blossom **bridge** photo (the one you shared). Keep it under ~1 MB. |
| `india-japan-summit.jpg` | The "It's real" section | A freely-licensed photo of the Aug-2025 summit (e.g. Wikimedia Commons / PIB), **with credit**. |

### Two easy ways to add an image
1. **Drag-and-drop (easiest):** open the README on github.com, click the ✏️ **edit** button, and drag your
   image straight into the editor. GitHub uploads it and pastes the link for you. Commit — done.
2. **Commit the file:** save the image in this `docs/` folder with the exact name above, then uncomment the
   matching `<!-- ![...](docs/...) -->` line in the README.

> The **demo video** works the same way — see the 🎬 Demo video section in the README for step-by-step
> instructions (drag your `.mp4` into the README editor and it becomes a playable video).
