# 🎯 Theme-Day Decision Sheet (use the moment 5 themes drop)

Don't fall in love with the "coolest" theme. Pick the one you can **prove** and **ship**
in limited solo time. Score each theme 1–5 on the five factors, multiply by the weight,
sum it. Highest total wins. Time-box this to **15 minutes**, then commit and don't look back.

| Factor | Weight | What a 5 looks like |
|---|---|---|
| **ML-leverage** | ×3 | A model/AI does the heavy lifting — plays to my strength, least glue code |
| **Provable** | ×3 | I can show a number/baseline/chart that proves it works (not just a claim) |
| **Data available** | ×2 | A usable dataset or API exists *today* — I won't waste days hunting data |
| **Demoable in 60s** | ×2 | One input → one impressive output that a judge instantly "gets" |
| **Scope fits solo** | ×2 | One sharp feature is enough to be compelling; not 5 features to be coherent |

### Tie-breakers (if two are close)
- Which one excites *you* more to work on for 7 days? (motivation is real fuel)
- Which has the clearer "scalable to Round 2/3" story?
- Which needs the *least* unfamiliar tech?

### Red flags — avoid a theme if…
- ⚠️ The only way to demo it is a mockup with no real working core.
- ⚠️ It needs data you'd have to collect/label yourself from scratch.
- ⚠️ It only impresses if *fully* built (no compelling thin slice).

### Once you've picked
1. Write a one-sentence problem statement: *"For [user], we [do X] so they can [outcome]."*
2. Define the ONE proof metric up front: *"Success = we beat [baseline] on [metric]."*
3. Tell me the theme + that sentence — we swap the slots and start building.
